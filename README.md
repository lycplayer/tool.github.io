- ⚡ **直链获取** —— 把网盘文件换成 HTTP 直链，交给本地下载器 / aria2 / IDM 跑满带宽。

- 💎 **液态玻璃界面** —— 内置桌面窗口，深色 / 浅色主题，跟随鼠标的玻璃高光质感。

1. 进入 [下载页](https://lycplayer.github.io/PAN/) 下载 `更好的网盘直链下载工具.exe`（单文件，双击即开，无需安装 Python）。
